TinComp

A small experimental systems programming language and native compiler for AMD64.

TinComp is an experimental imperative programming language together with a native compiler written entirely in Python.

The compiler translates source code into AMD64 assembly.

The project was created primarily as a learning project in compiler construction and systems programming.

TinComp is under still development and it is not a production ready software although the compiler should be mainly functional.

Unfortunaltely TinComp's manual is in Finnish.

Highlights

✓ Native AMD64 code generation

✓ Runtime library

✓ Arrays

✓ Structs

✓ Strings

✓ Basic compiler optimizations

✓ Extensive end-to-end testing

Tarvitset:

  • GNU/Linux-ympäristön (AMD64/x86-64)
  • Pythonin (projektin dokumentaation mukaan vähintään 3.11)
  • järjestelmän assemblerin (esim. GNU as), joka löytyy yleensä valmiina Linuxista

Kääntäjän käyttö 1

Projektin juuresta voit ajaa kääntäjän suoraan:

./tincomp ohjelma.tin ohjelma

- tuottaa suoritettavan binäärin ohjelma

./tincomp ohjelma.tin ohjelma.s -S

- tuottaa vain assembly-tiedoston ohjelma.s

Kääntäjän käyttö 2

1. Kirjoita lähdekoodi tiedostoon, esim. `hello.tin`

2. Käännä:

./compile hello.tin hello

3. Aja ohjelma:

./hello

Jos haluat tutkia kääntäjän tuottamaa assemblyä:

./compile hello.tin hello.s -S

Opas - Ohjelmointikieli

Alla tiivis käytännön opastus tärkeimpiin rakenteisiin.

5.1 Muuttujat

Muuttuja määritellään avainsanalla var:

var x = 10;
var valmis = true;
var n: Int = 123;

Huomioita:

  • Tyyppimäärittely (: Int, : Bool) on mahdollinen.
  • Käytännössä on suositeltua käyttää eksplisiittisiä tyyppimerkintöjä erityisesti Int/Bool-arvoille.
  • Merkkijonot käyttäytyvät viitteinä (muistiosoitteina), joten niiden kanssa kannattaa välttää turhaa tyyppikikkailua.

5.2 If-else

Perusmuoto:

if x > 0 then {
	print_int(x);
} else {
	print_int(0);
}

Myös ilman else-haaraa:

if valmis == true then {
	print_str("OK");
}

Huomioita:

  • Ehto on binäärioperaatio ([expr] op [expr]), esim. >, <, >=, <=, ==, !=, or.
  • Pidä syntaksi tarkkana: avainsanat then ja lohkot { ... } ovat olennaisia.

5.3 While-silmukka

Perusmuoto:

var i = 0;
while i < 5 do {
	print_int(i);
	i = i + 1;
}

break ja continue ovat tuettuja:

while i < 10 do {
	i = i + 1;
	if i == 3 then { continue; }
	if i == 8 then { break; }
	print_int(i);
}

Huomio:

  • Älä yritä varata taulukoita silmukan sisällä (array(...)), koska taulukkomuisti varataan käännöksen aikana.

5.4 Näkyvyysalueet (scope)

Kieli käyttää lohkokohtaisia näkyvyysalueita:

var a = 1;
if a == 1 then {
	var b = 2;
	print_int(b);
}

print_int(b);

Nyt saat virheilmoitukset Line 7: variable b is out of the context!, koska b ei ole määritelty tässä kontekstissa.

Eli:

  • Sisempi lohko näkee ulomman lohkon muuttujat.
  • Ulompi lohko ei näe sisemmässä lohkossa määriteltyjä muuttujia.

5.5 Funktiot

Perusmuoto:

fun summa(x, y): Int {
	return x + y;
}

Käyttö:

var z = summa(2, 3);
print_int(z);

Huomioita:

  • Paluutyyppi on valinnainen (oletus Int), mutta selkeys yleensä paranee kun tyyppi annetaan.
  • Parametrien maksimimäärä on 6.
  • Hyvä käytäntö on kirjoittaa pääohjelma begin()-funktioon ja kutsua se lopussa.

5.6 Array (taulukot)

Taulukko luodaan:

var arr = array(10);

Arvon asetus ja haku:

set(arr, 0, 42);
var eka = get(arr, 0);
print_int(eka);

Huomioita:

  • Koon on oltava positiivinen vakio (array(10)), ei muuttuja tai lauseke.
  • Taulukko on viite muistialueeseen: kopiointi var b = arr; tarkoittaa, että molemmat viittaavat samaan taulukkoon.

5.7 Structs (rakenteet)

Määrittely:

define struct HENKILO = { nimi, ika };

Instanssin luonti ja käyttö:

var h = New(HENKILO);
write_long(h, HENKILO->nimi, "Ada");
write_long(h, HENKILO->ika, 28);

print_str(read_long(h, HENKILO->nimi));
print_int(read_long(h, HENKILO->ika));

Huomioita:

  • New(...) näyttää funktiokutsulta, mutta on kielen oma rakenne.
  • Rakenteet käyttävät ajonaikaista heap-muistia.
  • Rakenne kannattaa määritellä ennen käyttöä (ennen instanssien luontia ja niitä käyttäviä funktioita).

6) Yleiset sudenkuopat ja huomiot

  • Funktioiden parametrimäärä on rajattu (maksimi 6).
  • Taulukon koko pitää antaa vakiona, koska muistivaraus tehdään käännösaikana.
  • Merkkijonot ovat käytännössä viitteitä muistiosoitteisiin (IntRef-tyyppinen malli), joten käsittele niitä varoen.
  • String-vakion suora palautus voi aiheuttaa ongelmia:
    • vältä mallia return "teksti";
    • käytä mieluummin muuttujaa tai funktiokutsun tulosta
  • Jos virheilmoitus tuntuu epämääräiseltä, tarkista ensin:
    • puolipisteet
    • sulkeiden/parien tasapaino
    • typo/whitespace-kohdat (kieli on joissain kohdissa herkkä muodolle)

    • vältä mallia return "teksti";

Pieni vinkki!

Vinkkejä ja parhaita käytäntöjä TinCompin käyttöön.

Suositeltu tapa on laittaa pääohjelma begin()-funktioon ja kutsua sitä tiedoston lopussa:

fun begin() {
	// pääohjelma
}

begin();

Tämä vähentää joitain harvinaisia tilanteita, joissa virheilmoitukset voivat olla vaikeammin tulkittavia.

Opas - Standardikirjasto

Pikainen katsaus TinCompin standardikirjastoon ja sen käyttöön.

  • str_cmp(s1: IntRef, s2: IntRef): Bool
    • vertaa kahta merkkijonoviitettä. Palauttaa true, jos sisällöt ovat samat, muuten false.
  • str_cat(s1: IntRef, s2: IntRef): Int
    • yhdistää kaksi merkkijonoa ja palauttaa viitteen uuteen merkkijonoon.
  • str_len(s1: IntRef): Int
    • palauttaa merkkijonon pituuden.

  • str_clone(s1: IntRef): Int

    • kloonaa merkkijonon s1 eli luo uuden, itsenäisen merkkijonon samalla sisällöllä.

  • print_str(s: Int)

    • tulostaa merkkijonon ja lisää rivinvaihdon loppuun.
  • print_str2(s: Int)
    • tulostaa merkkijonon ilman rivinvaihtoa.
  • str_to_int(s: Int): Int
    • muuntaa merkkijonon kokonaisluvuksi.
  • int_to_str(s: Int): Int
    • muuntaa kokonaisluvun merkkijonoksi.
  • get_char_from_str(s: Int, index: Int): IntRef
    • palauttaa merkkijonosta s kohdassa index olevan merkin uutena yhden merkin merkkijonona.
  • input_str(): Int
    • lukee käyttäjän syötteen (stdin) ja palauttaa viitteen syötettyyn merkkijonoon.
  • create_empty_str(): Int
    • luo tyhjän merkkijonon ja palauttaa viitteen siihen.

8.2 Merkkijonojen käyttö käytännössä

Merkkijonot ovat tässä kielessä viitteitä muistiosoitteisiin (IntRef-malli). Käytännössä tämä tarkoittaa:

  • käsittele merkkijonoja funktioiden kautta (str_cat, str_cmp, str_len, ...)
  • vältä turhaa aritmetiikkaa merkkijonomuuttujilla
  • jos tarvitset "alkuarvoksi tyhjän merkkijonon", käytä create_empty_str()

Esimerkki:

fun begin() {
    var nimi = create_empty_str();
    print_str2("Anna nimesi: ");
    nimi = input_str();

    var tervehdys = str_cat("Hei ", nimi);
    print_str(tervehdys);

    if str_cmp(nimi, "admin") then {
        print_str("Tunnistettu ylläpitäjäksi");
    } else {
        print_str("Tavallinen käyttäjä");
    }

    var pituus = str_len(nimi);
    print_str2("Nimen pituus: ");
    print_int(pituus);
}

begin();

8.3 Tärkeät huomiot merkkijonoista

  • Vältä suoraa merkkijonovakion palautusta funktiosta (return "teksti";), koska se voi aiheuttaa ongelmia.
  • Käytä palautukseen mieluummin muuttujaa tai funktiokutsun tulosta.
  • Jos merkkijonoa pitää yhdistellä paljon, käytä välivaiheissa muuttujia selkeyden vuoksi.
  • Muista, että print_str lisää rivinvaihdon, print_str2 ei lisää.

8.4 Pikareseptit (yleiset käyttötapaukset)

Resepti 1: Syöte -> vertailu -> tulostus

fun begin() {
    print_str2("Anna komento (start/stop): ");
    var cmd = input_str();

    if str_cmp(cmd, "start") then {
        print_str("Käynnistetään");
    } else {
        if str_cmp(cmd, "stop") then {
            print_str("Pysäytetään");
        } else {
            print_str("Tuntematon komento");
        }
    }
}

begin();

Resepti 2: Syöte merkkijonona -> muunnos numeroksi

fun begin() {
    print_str2("Anna kokonaisluku: ");
    var s = input_str();

    var n = str_to_int(s);
    var plus_yksi = n + 1;

    print_str2("Luku + 1 = ");
    print_int(plus_yksi);
}

begin();

Resepti 3: Numeron muuttaminen merkkijonoksi ja yhdistäminen

fun begin() {
    var pisteet = 42;
    var teksti = str_cat("Pisteet: ", int_to_str(pisteet));
    print_str(teksti);
}

begin();

Resepti 4: Yksittäisen merkin poiminta merkkijonosta

fun begin() {
    var sana = "TinComp";
    var eka = get_char_from_str(sana, 0);
    print_str2("Ensimmäinen merkki: ");
    print_str(eka);
}

begin();

Huom: get_char_from_str palauttaa yhden merkin mittaisen merkkijonon (viitteen), ei erillistä char-tyyppiä.
